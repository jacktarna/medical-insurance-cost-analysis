# Medical Insurance Cost Analysis

## Project Overview

An end-to-end data analytics project exploring factors associated with medical insurance charges using Python, MySQL, and Power BI.

## Tools Used

* **Python:** Pandas, data cleaning, feature engineering
* **MySQL:** Data storage, validation, aggregation, and SQL analysis
* **Power BI:** Interactive dashboard, KPI card, charts, and slicers

## Workflow

1. Cleaned the original dataset and removed an exact duplicate.
2. Created age groups and BMI categories in Python.
3. Imported the cleaned data into MySQL and analyzed insurance charges using SQL.
4. Built an interactive Power BI dashboard with KPI and comparison charts.

## Key Findings

* The cleaned dataset contains 1,337 records.
* Average insurance charges were approximately $13,279.
* Average charges differed substantially between smokers and non-smokers.
* Average charges varied across age groups, regions, and BMI categories.

These are descriptive findings and do not establish causation.

## Project Files

* `notebooks/` — Python cleaning and preparation
* `sql/` — Data import and analysis queries
* `powerbi/` — Power BI dashboard and preview

## Data Source

Medical Cost Personal Datasets, available on Kaggle. Credit the original dataset creator and follow the dataset's terms.

## Disclaimer

This project is for educational and portfolio purposes. The findings describe associations in the dataset and should not be interpreted as causal or medical advice.
